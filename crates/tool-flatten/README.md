# tool-flatten（文件夹平铺）

把目标文件夹下**每个直接子文件夹里的普通文件**移动到目标文件夹根目录，自动处理重名，并在结束后删除留下的空子文件夹。实现 `toolbox_core::Tool`，工具 id 为 `folder-flatten`。

## 功能与规则

- **只处理直接子文件夹**：不递归。子文件夹里若还有子目录，该子目录不处理、不移动、也不删除；因此该子文件夹会被视为「非空」而保留。
- **只移动普通文件**：目录项（子文件夹）不移动；符号链接 / 目录联接也不跟随、不移动。
- **绝不覆盖**：目标根目录已有同名文件时，默认在扩展名前追加 ` (1)`、` (2)`……直到不冲突。`a.tar.gz` 变成 `a.tar (1).gz`，`.gitignore` 变成 `.gitignore (1)`。冲突判定忽略大小写，避免 Windows 上 `A.txt` 覆盖 `a.txt`。
- **冲突策略**：`on_conflict` 默认 `auto_rename`；设为 `skip` 时跳过冲突文件并在报告中逐条列出。两种策略都不会覆盖已有文件。
- **移动方式**：优先 `std::fs::rename`；失败（如跨盘符）回退「复制到目标 + 删除源文件」。复制或删除任一步失败都会清理已复制的目标文件，不留半成品。执行前若发现目标已存在则直接报错。
- **空目录清理**：移动完成后，若子文件夹为空（含原本就空的）则删除；若残留子目录或文件则保留，并在报告详情中说明。
- **选项**：`dry_run`（bool，默认 `false`）、`on_conflict`（字符串，默认 `auto_rename`，可选 `skip`）。未知策略返回参数错误。

## dry-run 预览

`dry_run = true` 时零修改：只扫描并生成计划写入 `ToolReport.details`，不移动、不删除、不加锁。报告统计中 `moved / renamed / dirs_removed` 均为 0，`found_files / skipped` 反映计划内容，详情里逐条列出「计划移动 / 计划跳过 / 计划检查并删除空子文件夹」。

## 报告

`ToolReport.message` 汇总：找到文件数、移动数、重命名数、删除空文件夹数、跳过数、失败数；失败数大于 0 时 `ok = false`。`ToolReport.details` 为逐条中文说明。

## 风险说明

- 文件会被移动到根目录，原子文件夹结构在文件移走后被删除；嵌套子目录不会被删除，但请先确认没有依赖原目录结构的程序。
- 同名文件会被改名而非覆盖；跨盘符回退为复制 + 删除，过程中断（断电 / 强制退出）理论上可能在目标留下新文件，源文件的删除只在复制成功后才执行。
- 文件名按 UTF-8 处理，极端情况下非 UTF-8 文件名在生成 `(1)` 后缀时可能被替换字符影响。
- 不修改注册表、不提权、不属于系统设置类工具。

## 编译验证（由主 Agent 执行）

```powershell
scripts\cargo.ps1 check -p tool-flatten --all-targets
scripts\cargo.ps1 test -p tool-flatten
```
