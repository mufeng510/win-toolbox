# 批量 HEIC 转 JPG 工具

在任意文件夹**空白处右键** → 「批量 HEIC 转 JPG」即可。

## 功能

- 转换当前文件夹中的 HEIC / HEIF 文件为 JPG，**输出在原位置**，不新建子文件夹
- 可选**转换成功后删除原 HEIC**（默认开启，点「开始转换」时会再次弹窗确认）
- 可选包含子文件夹（默认开启）
- JPG 质量 1–100 可调，默认 95
- 自动按 EXIF 旋转方向校正，输出统一为 sRGB
- 目录中没有 HEIC 时会提示，不会误动别的文件
- 已有同名 JPG 会跳过，且**不会**删除对应的 HEIC
- 删除原文件前会用 ImageMagick 校验生成的 JPG 确实可正常打开，校验失败则保留原文件

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `HeicToJpg.exe` | 主程序（图形界面） |
| `批量转换-命令行.ps1` | 命令行批量转换，供脚本调用 |
| `安装右键菜单.ps1` | 注册右键菜单（当前用户，免管理员） |
| `卸载右键菜单.ps1` | 移除右键菜单 |
| `HeicToJpg.cs` | 源码 |
| `app.manifest` | DPI 感知声明（Per-Monitor V2） |

## 依赖

需要安装 [ImageMagick](https://imagemagick.org/)（本机路径：`C:\Program Files\ImageMagick-7.1.2-Q16`）。
程序会自动在常见安装位置和 PATH 中查找 `magick.exe`，找不到时界面会明确提示。

## 命令行用法

```powershell
# 默认：质量 95，递归，成功后删除原 HEIC
.\批量转换-命令行.ps1 "D:\素材\新品拍摄"

# 质量 90 且保留原文件
.\批量转换-命令行.ps1 "D:\素材\新品拍摄" -质量 90 -保留原文件

# 只处理当前目录，不进子文件夹
.\批量转换-命令行.ps1 "D:\素材\新品拍摄" -不递归
```

退出码：`0` 全部成功，`1` 有失败项，`2` 找不到 ImageMagick 或目录无效。

## 重新编译

```powershell
cd C:\Tools\HeicToJpg
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /optimize+ `
  /codepage:65001 /win32manifest:app.manifest /out:HeicToJpg.exe `
  /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.Core.dll `
  HeicToJpg.cs
```

隐藏参数：`--probe` 输出布局与 DPI 诊断信息，`--selftest "<目录>" <质量> <递归0|1> <删除0|1>` 无界面运行。
